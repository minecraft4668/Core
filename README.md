# Core

---

A Terminal User Interface made for Unix-like terminal.

# General

---

Core is a TUI (Terminal User Interface) software solution for Unix-like terminal system(e.g. bash, zsh, powershell(compatible)).

It provided two version.

* **Shell version** : You can use it in shell.
* **C++ solution** : Use it for your project by libraries we provided.
